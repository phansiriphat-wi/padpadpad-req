# Feature: เช็คชื่อเข้าร่วมกิจกรรม (Activity Attendance)
Spec ID: SPEC-ATT-013 | Source: SRS v1.0 (UC-13) | Use case: UC-13
Owner: คณะกรรมการ | Status: Draft v1 | Updated: 2569-09-19

## Goal
คณะกรรมการสามารถตรวจสอบและบันทึกการเข้าร่วมกิจกรรมของผู้เข้าร่วมค่ายเป็นรายบุคคล
ระบบบันทึกสถานะการเข้าร่วมกิจกรรมของผู้เข้าร่วมแต่ละคน เพื่อให้สามารถตรวจสอบประวัติการเข้าร่วมกิจกรรมได้อย่างถูกต้อง

## Scope
### In scope
- แสดงรายการกิจกรรมค่ายที่มีอยู่ในระบบ
- เลือกกิจกรรมที่ต้องการเช็คชื่อ
- แสดงรายชื่อผู้เข้าร่วมค่ายของกิจกรรม
- บันทึกสถานะการเข้าร่วมกิจกรรมของผู้เข้าร่วม
- ระบุสถานะ มา, สาย, ลา หรือขาด
- บันทึกประวัติการเข้าร่วมกิจกรรมของผู้เข้าร่วมแต่ละคน

### Out of scope
- การจัดตารางกิจกรรมค่าย
- การเพิ่มหรือแก้ไขรายชื่อผู้เข้าร่วมค่าย
- การจัดกลุ่มหรือฝ่ายงานของผู้เข้าร่วม
- การแก้ไขข้อมูลกิจกรรม
- การสมัครเข้าร่วมค่าย

## Constraints
- CON-ATT-01 ต้องมีรายชื่อผู้เข้าร่วมค่ายในระบบก่อนจึงสามารถเช็คชื่อได้
- CON-ATT-02 ต้องมีกิจกรรมที่กำหนดไว้ในระบบก่อนจึงสามารถเช็คชื่อได้
- CON-ATT-03 การบันทึกการเข้าร่วมกิจกรรมต้องดำเนินการโดยคณะกรรมการ
- CON-ATT-04 ผู้เข้าร่วมแต่ละคนต้องสามารถระบุสถานะการเข้าร่วมกิจกรรมได้
- IF-ATT-01 ระบบต้องดึงรายชื่อผู้เข้าร่วมจากข้อมูลผู้เข้าร่วมค่ายที่มีอยู่ในระบบ
- IF-ATT-02 ระบบต้องบันทึกผลการเช็คชื่อโดยอ้างอิงกิจกรรมและผู้เข้าร่วมแต่ละคน

## Requirements
- FR-ATT-01 ระบบต้องแสดงรายการกิจกรรมที่สามารถเช็คชื่อได้  <- UC-13 main flow ขั้น 1
- FR-ATT-02 เมื่อคณะกรรมการเลือกกิจกรรม ระบบต้องแสดงรายชื่อผู้เข้าร่วมค่ายสำหรับกิจกรรมนั้น  <- UC-13 main flow ขั้น 2
- FR-ATT-03 ระบบต้องให้คณะกรรมการเช็คชื่อผู้เข้าร่วมแต่ละคน  <- UC-13 main flow ขั้น 3
- FR-ATT-04 ระบบต้องให้คณะกรรมการระบุสถานะการเข้าร่วมของผู้เข้าร่วมเป็น มา, สาย, ลา หรือขาด  <- UC-13 main flow ขั้น 4
- FR-ATT-05 เมื่อคณะกรรมการบันทึกผล ระบบต้องบันทึกสถานะการเข้าร่วมกิจกรรมของผู้เข้าร่วมแต่ละคน  <- UC-13 main flow ขั้น 5
- FR-ATT-06 หากระบบไม่พบรายชื่อผู้เข้าร่วม ระบบต้องแจ้งเตือนคณะกรรมการ  <- UC-13 alternative flow 2a

## Quality Requirements
- NFR-USE-01 คณะกรรมการต้องสามารถเช็คชื่อและบันทึกสถานะการเข้าร่วมกิจกรรมได้อย่างชัดเจนและไม่ซับซ้อน
- NFR-DATA-01 ระบบต้องบันทึกสถานะการเข้าร่วมให้ถูกต้อง โดยเชื่อมโยงกับกิจกรรมและผู้เข้าร่วมแต่ละคน
- NFR-SEC-01 เฉพาะคณะกรรมการเท่านั้นที่สามารถบันทึกหรือแก้ไขสถานะการเข้าร่วมกิจกรรมได้
- NFR-REL-01 ระบบต้องไม่บันทึกผลการเช็คชื่อ หากไม่สามารถระบุผู้เข้าร่วมหรือกิจกรรมที่เกี่ยวข้องได้อย่างถูกต้อง

## Acceptance Criteria

- [ ]   AC-ATT-01 (FR-ATT-01, FR-ATT-02)
        Given มีตารางกิจกรรมและรายชื่อผู้เข้าร่วมค่ายในระบบ
        When  คณะกรรมการเลือกกิจกรรมที่กำลังดำเนินอยู่
        Then  ระบบต้องแสดงรายชื่อผู้เข้าร่วมสำหรับกิจกรรมนั้น
- [ ]   AC-ATT-02 (FR-ATT-03, FR-ATT-04, FR-ATT-05)
        Given คณะกรรมการเลือกกิจกรรมและระบบแสดงรายชื่อผู้เข้าร่วม
        When  คณะกรรมการทำเครื่องหมาย "เข้าร่วม" ให้ผู้เข้าร่วมตามรายชื่อและกดบันทึก
        Then  ระบบต้องบันทึกประวัติการเข้าร่วมกิจกรรมของนักศึกษาแต่ละคนเป็นสถานะ "มา"
- [ ]   AC-ATT-03 (FR-ATT-04, FR-ATT-05)
        Given ระบบแสดงรายชื่อผู้เข้าร่วมของกิจกรรม
        When  คณะกรรมการกำหนดสถานะเป็น "สาย", "ลา" หรือ "ขาด" และกดบันทึก
        Then  ระบบต้องบันทึกสถานะการเข้าร่วมของผู้เข้าร่วมแต่ละคนตามที่กำหนด
- [ ]   AC-ATT-04 (FR-ATT-06)
        Given กิจกรรมที่เลือกไม่มีรายชื่อผู้เข้าร่วมในระบบ
        When  คณะกรรมการเปิดหน้าเช็คชื่อกิจกรรม
        Then  ระบบต้องแจ้งเตือนว่าไม่พบรายชื่อผู้เข้าร่วม
- [ ]   AC-ATT-05 (NFR-DATA-01)
        Given คณะกรรมการบันทึกผลการเช็คชื่อสำเร็จ
        When  ตรวจสอบประวัติการเข้าร่วมกิจกรรมของผู้เข้าร่วม
        Then  ระบบต้องแสดงกิจกรรมและสถานะการเข้าร่วมที่บันทึกไว้ถูกต้อง

## Assumptions & Open Questions
- ASM-01 รายชื่อผู้เข้าร่วมค่ายถูกบันทึกในระบบก่อนเริ่มกิจกรรม
- ASM-02 ตารางกิจกรรมถูกกำหนดไว้ในระบบก่อนเริ่มการเช็คชื่อ
- ASM-03 ผู้เข้าร่วมหนึ่งคนสามารถมีสถานะการเข้าร่วมได้หนึ่งสถานะต่อหนึ่งกิจกรรม
- ASM-04 สถานะการเข้าร่วมที่ระบบรองรับคือ มา, สาย, ลา และขาด
- Q-01 สามารถแก้ไขสถานะการเข้าร่วมหลังจากบันทึกแล้วได้หรือไม่?
- Q-02 หากแก้ไขสถานะการเข้าร่วม ระบบต้องเก็บประวัติการแก้ไขหรือไม่?
- Q-03 การเช็คชื่อสามารถทำย้อนหลังได้หรือไม่?
- Q-04 ผู้เข้าร่วมสามารถตรวจสอบประวัติการเข้าร่วมกิจกรรมของตนเองได้หรือไม่?
